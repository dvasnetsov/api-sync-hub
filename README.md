# SpecBridge

SpecBridge is a small workspace for publishing stable OpenAPI URLs and syncing specs between
Apidog source and publish projects.

## Production

The project is deployed on Cloudflare Workers.

- Site: https://specbridge.specbridge-demo.workers.dev
- Deployment target: Cloudflare Workers
- Worker config generated by build: `dist/server/wrangler.json`

## Local Development

```bash
bun install
bun run dev
```

## Build And Deploy

```bash
bun run build
bun run deploy:only
```

`bun run deploy` runs both steps:

```bash
bun run build && wrangler deploy --config dist/server/wrangler.json
```

Required runtime variables are stored outside git in `.env` and Cloudflare secrets. Do not commit
`SUPABASE_SERVICE_ROLE_KEY`.

## Parser And Sync Logic

The main Apidog/OpenAPI sync logic lives in `src/lib/specs.functions.ts`.

Important areas:

- Pull from Apidog: `syncFromApidog`
- Push to Apidog: `pushToApidog`
- OpenAPI server parsing: `normalizeApidogServers`, `extractServersFromSpecText`
- Apidog environment parsing attempt: `fetchEnvironmentExportDataFromApidog`,
  `normalizeEnvironmentForExport`
- Server filtering before push: `filterSpecServersForPush`
- Auth normalization before push: `enrichSpecForApidogImport`, `normalizeSecurityForApidogImport`
- Folder/tag/order normalization before push: `enrichSpecForApidogImport`, `applyOrderNormalization`

The collection settings UI for selecting servers and push rules is in
`src/components/collection/SettingsTab.tsx`.
